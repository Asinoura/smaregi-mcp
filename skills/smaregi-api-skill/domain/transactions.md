# 取引データ (transactions)

## 取引区分 (transactionHeadDivision)

| 値 | 意味 |
|----|------|
| 1 | 通常取引（売上） |
| 2 | 返品 |
| 3 | 取消 |
| 4 | 値引き |
| 5 | 入金 |
| 6 | 出金 |
| 7 | 券売 |
| 8 | 棚卸 |
| 9 | 予約 |
| 10 | 受注 |

## 取消区分 (cancelDivision)

| 値 | 意味 |
|----|------|
| 0 | 通常（取消されていない） |
| 1 | 取消済み |

## 純売上の計算

- ⚠️ 純売上の集計には `transaction_head_division=1` AND `cancel_division=0` の**両方**が必要です
- ⚠️ cancel_division を指定しないと、取消済み取引も含まれ金額が正しくなりません
- ⚠️ transaction_head_division を指定しないと、返品・入金・出金なども含まれます

## 金額フィールド

- `subtotal` — 小計（税抜）
- `total` — 合計（税込）
- `tax` — 税額
- ⚠️ 純売上金額は `total` フィールドの合計を使ってください（`subtotal` は税抜です）

## 期間制限

- ⚠️ 1回のリクエストで取得できる期間上限は **31日間** です
- ⚠️ 31日を超える期間のデータが必要な場合は、月ごとに分割してリクエストしてください
- 例: 3ヶ月分 → 1月、2月、3月の3回に分けてリクエスト

## 明細レベル (with_details)

| 値 | 内容 | 用途 |
|----|------|------|
| none | 取引ヘッダのみ | 件数・合計金額の集計 |
| summary | ヘッダ＋概要 | 日次集計 |
| all | ヘッダ＋全明細 | 商品別の売上分析 |

- ⚠️ `with_details=all` はレスポンスが大きくなります。商品別分析が不要なら `none` を使ってください

## 注意事項

- ⚠️ customerCount は来客数であり、取引件数ではありません
- ⚠️ 日付フォーマットは ISO 8601（例: `2024-01-01T00:00:00+09:00`）
