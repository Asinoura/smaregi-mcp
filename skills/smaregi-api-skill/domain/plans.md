# スマレジ プラン別API制約

## プラン一覧

| プラン | 月額 | 主な機能 |
|--------|------|---------|
| スタンダード | 無料 | POS基本機能 |
| プレミアム | 有料 | 売上分析、在庫管理 |
| プレミアムプラス | 有料 | 顧客管理、ポイント |
| フードビジネス | 有料 | 飲食店向け機能 |
| リテールビジネス | 有料 | 小売店向け機能 |

## API利用可能範囲

- ⚠️ 在庫API (`/stock`) はプレミアムプラン以上でのみ利用可能です
- ⚠️ 顧客API (`/customers`) はプレミアムプラスプラン以上でのみ利用可能です
- 取引API (`/transactions`) と商品API (`/products`) は全プランで利用可能です
- 店舗API (`/stores`) は全プランで利用可能です

## レート制限

- ⚠️ APIリクエストにはレート制限があります（プランにより異なる）
- 短時間に大量のリクエストを送ると 429 エラーが返されます
